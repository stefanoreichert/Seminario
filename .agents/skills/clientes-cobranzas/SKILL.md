# Clientes, cuentas y autorizaciones
- Registrar identificación comercial, CUIT, contactos y múltiples direcciones de entrega.
- Mantener historial de cuentas corrientes, cobros y condiciones comerciales según alcance aprobado.
- Solo roles autorizados pueden aprobar o rechazar salidas; registrar usuario y marca temporal.
- Depósito consulta aprobación, nunca la autoconcesiona.
- No asumir que el sistema sustituye al software Alma ni que emite comprobantes fiscales: documento TP Análisis lo excluye, Seminario lo contempla; solicitar decisión antes de integrar ARCA.
- Proteger información personal, permisos por rol y registros de auditoría.
