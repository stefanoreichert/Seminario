# Testing y calidad
- Unitarias para invariantes de dominio y casos de uso con dobles de puertos.
- Integración para repositorios, transacciones, permisos, índices, restricciones y concurrencia.
- Funcionales HTTP para validación y autorización por rol.
- Cubrir: pedidos duplicados, entregas parciales, falta de stock, despacho sin autorización, lotes, devoluciones y auditoría.
- Informar comandos ejecutados, resultados y pruebas no ejecutadas.
- No afirmar que algo funciona si no se probó; evitar migraciones destructivas y borrado de datos.
