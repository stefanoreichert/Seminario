# Procedimiento obligatorio para Codex
1. Leer AGENTS.md, skills relevantes, requisitos y código existente.
2. Describir objetivo y casos de uso afectados, supuestos y conflictos.
3. Presentar plan corto de archivos y límites de arquitectura.
4. Implementar mínimo cambio coherente con puertos/adaptadores.
5. Ejecutar tests, formato y análisis estático disponibles.
6. Reportar archivos modificados, comandos, resultados, pendientes y decisiones que necesitan aprobación.
- No implementar módulos completos si el pedido es solo maquetación.
- No tocar credenciales, claves, entornos productivos ni datos reales.
- No hacer commits/push sin pedido explícito.
